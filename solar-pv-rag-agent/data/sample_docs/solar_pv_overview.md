## 一、光伏材料分类

太阳能电池的核心是吸收层材料。按材料体系可分为：

1. **晶硅（c-Si）**：包括单晶硅与多晶硅，是当前商用主流，带隙约 1.12 eV，
   实验室最高转换效率约 26.8%，具有稳定性好、产业链成熟等优点。
2. **薄膜电池**：包括碲化镉（CdTe，带隙 1.45 eV）、铜铟镓硒（CIGS，带隙约
   1.1 eV，可调）等，用料少、可柔性化，但部分材料含稀有或有毒元素。
3. **III-V 族化合物**：如砷化镓（GaAs，带隙 1.42 eV），效率可达 29% 以上，
   但成本高，主要用于航天与聚光电池。
4. **钙钛矿电池**：以 ABX3 结构（如 MAPbI3、FAPbI3）为代表，带隙约 1.5 eV
   可调，单结效率已超过 26%，成本低、可溶液加工，但长期稳定性是短板。

## 二、钙钛矿太阳能电池

钙钛矿太阳能电池（Perovskite Solar Cells, PSCs）以有机-无机杂化卤化物钙钛矿为
吸光层。典型材料 MAPbI3（甲胺铅碘）带隙约 1.55 eV，FAPbI3（甲脒铅碘）带隙约
1.48 eV。

**主要优势**：
- 吸光系数高，数百纳米薄膜即可充分吸光；
- 带隙可调，可与其他电池组成叠层结构；
- 可低温溶液法制备，工艺简单、成本低；
- 效率提升迅速，单结认证效率已超过 26%。

**主要挑战**：
- 湿热环境下的分解（铅卤化物对水敏感）；
- FAPbI3 的光活性相（α 相）在室温下易转变为非光活性相；
- 铅的毒性带来的环保顾虑；
- 大面积制备的均匀性与稳定性。

**改善稳定性的途径**：组分工程（如掺入 Cs、MA 混合阳离子）、界面钝化、疏水
封装等。

## 三、理论效率极限

单结太阳能电池的理论效率上限由 Shockley-Queisser（S-Q）极限决定。在 AM1.5G
光谱下，最优带隙约为 1.3–1.4 eV，对应极限效率约 33.7%。带隙偏离最优值都会导致
效率下降：带隙过小则热化损失增大，带隙过大则吸收的光子数减少。

带隙（Eg，eV）与吸收截止波长（λ，nm）的关系为：

    λ = 1240 / Eg

例如 MAPbI3 带隙 1.55 eV，对应吸收截止波长约 800 nm。

## 四、叠层电池

将不同带隙的子电池串联，可突破单结 S-Q 极限。钙钛矿/晶硅叠层电池是目前最
受关注的方向之一，其认证效率已超过 30%。
